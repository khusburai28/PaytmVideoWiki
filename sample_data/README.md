# Sample Documents

Synthetic industrial documents for testing the ingestion pipeline end-to-end. **Not real customer data** — generated by `generate_samples.py` (uses PyMuPDF, Pillow, and pandas/openpyxl, all already in `backend/requirements.txt`).

Regenerate with:
```bash
docker cp sample_data/generate_samples.py videorag-backend:/tmp/generate_samples.py
docker compose exec backend python3 -c "
import sys; sys.path.insert(0, '/tmp')
import generate_samples
generate_samples.OUT = __import__('pathlib').Path('/tmp/sample_out')
for fn in ['make_pump_procedure','make_boiler_inspection','make_work_orders_spreadsheet','make_nameplate_image','make_pid_diagram_image']:
    getattr(generate_samples, fn)()
"
# then docker cp each file out of /tmp/sample_out/... into the matching sample_data/ subfolder
```

## Files

| File | Type | What it tests |
|---|---|---|
| `pdf/pump_maintenance_procedure.pdf` | PDF | Digital-text PDF extraction, page chunking |
| `pdf/boiler_inspection_report.pdf` | PDF | Same, with a different asset and inspector |
| `spreadsheets/work_orders.xlsx` | Spreadsheet | Multi-sheet XLSX parsing (`WorkOrders` + `SparePartsUsage`), row-group chunking |
| `images/equipment_nameplate.png` | Image | Gemini-vision OCR on a nameplate-style image |
| `images/simple_pid_diagram.png` | Image | Gemini-vision description of a labeled diagram (non-text-heavy) |

## Why these specific files prove the "unified intelligence" story

The equipment tags are **deliberately reused across every format**:

- **P-204** (centrifugal pump) — appears in the maintenance procedure PDF, the P&ID diagram image, and two rows in the work-orders spreadsheet
- **B-102** (package boiler) — appears in the inspection report PDF, the nameplate image, the P&ID diagram, and two rows in the work-orders spreadsheet
- **V-310** (control valve) — appears in the P&ID diagram and one work order

After ingesting all five files, open **Knowledge Graph** in the app: P-204 and B-102 should each appear as a *single* node with edges into every document that mentions them, and personnel (Rajesh Kumar, Priya Sharma), dates, and the regulation references (OISD-STD-105, PESO/IBR) should show up as connected entities too.

## Suggested test flow

1. Upload all 5 files (any order) via the "Ingest & Index" flow.
2. Open **Knowledge Graph** — confirm P-204 and B-102 are cross-linked across document types.
3. Open **Copilot** (corpus-wide, no document selected) and ask: *"What work orders exist for B-102 and what does its nameplate say?"* — the answer should cite both the spreadsheet and the image.
4. Open the pump procedure PDF directly and ask a document-scoped question — confirm the citation shows a page number, and clicking it jumps the PDF viewer to that page.
